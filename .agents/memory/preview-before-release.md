name: Preview before release
description: The user's release/testing boundary for this project.
---

Keep changes local and leave the development preview running until the user has manually tested every flow. Do not push to GitHub or publish before the user explicitly says manual testing is complete.

**Why:** The user wants to verify the complete app flow themselves before any release.

**How to apply:** For project work, do not use Git push or publishing actions while this boundary remains in effect; preserve the active preview server for manual testing.
