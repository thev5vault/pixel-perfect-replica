---
name: Certificate print watermark
description: Prevent the passport's screen watermark from interfering with multi-page PDF output.
---

Keep the certificate watermark out of paged print output unless it can repeat within each page's safe area.

**Why:** A watermark positioned relative to a long document can land at page boundaries or inside the printable margins, reducing readability.

**How to apply:** Treat the screen watermark separately from PDF pagination. Verify long multi-page PDFs before re-enabling it for print.
