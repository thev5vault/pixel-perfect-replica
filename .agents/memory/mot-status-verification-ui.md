---
name: MOT status and verification UI
description: Presentation rule for shared DVSA verification pills and MOT validity summaries.
---

Use the shared DVSA pill only to indicate that the vehicle data came from the official DVSA source. Show MOT validity, expiry dates, and days remaining in the dedicated MOT status card instead of repeating those values in the verification pill.

**Why:** Combining source provenance and roadworthiness status repeated expiry information across the Glovebox and Passport and made narrow-screen pills overflow.

**How to apply:** When adjusting shared MOT status or passport badges, preserve this separation; keep same-day retest outcomes explicit in the test-history entries.
