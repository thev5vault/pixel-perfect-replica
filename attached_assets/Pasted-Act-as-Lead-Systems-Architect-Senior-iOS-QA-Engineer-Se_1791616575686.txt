### 2. AI Vision Processing & Structured JSON Output
- Gemini / OpenAI Vision Integration:
  * Send image base64 buffer to the Vision model using structured JSON schema output.
  * Extracted Fields Required:
    - `garageName` (string): Name of workshop, dealer, or stamp.
    - `vatNumber` (string, optional): Company or VAT registration.
    - `date` (string): Standardized to UK format `DD/MM/YYYY`.
    - `mileage` (number): Vehicle mileage recorded on document.
    - `category` (enum): "Full Service", "Interim Service", "Major Repair", "MOT", "Modification", or "Oil Change".
    - `totalCost` (number): Total in GBP (£).
    - `workSummary` (string): Clean summary of work performed, parts replaced, or stamp notes.
    - `confidenceScore` (string): "HIGH", "MEDIUM", or "LOW".
- Graceful API Fallback:
  * Wrap AI calls in robust try/catch.
  * If the AI key is unconfigured or call fails, return HTTP 500 with a clean user alert: "Unable to auto-scan document right now. Please enter details manually."
