2. HIDE FLOATING BOTTOM NAVBAR WHEN MOBILE KEYBOARD IS ACTIVE:
   - In `App.jsx` / main layout component, add keyboard/focus event listeners to hide the floating `<nav>` when an input or textarea is actively focused:
     ```javascript
     const [isTyping, setIsTyping] = useState(false);
     useEffect(() => {
       const handleFocusIn = (e) => {
         if (['INPUT', 'TEXTAREA', 'SELECT'].includes(e.target.tagName)) setIsTyping(true);
       };
       const handleFocusOut = () => setIsTyping(false);
       window.addEventListener('focusin', handleFocusIn);
       window.addEventListener('focusout', handleFocusOut);
       return () => {
         window.removeEventListener('focusin', handleFocusIn);
         window.removeEventListener('focusout', handleFocusOut);
       };
     }, []);
     ```
   - On the floating `<nav>` element, conditionally apply `hidden` when `isTyping` is true (`className={${isTyping ? 'hidden' : 'fixed bottom-4 ...'}}`). This prevents the navbar from colliding with the iOS virtual keyboard.

3. MODAL AUTO-SCROLL ON INPUT FOCUS:

     `onFocus={(e) => e.target.scrollIntoView({ behavior: 'smooth', block: 'center' })}`
   - Add `pb-48` bottom scroll padding inside long modal scroll containers so the lowest input fields can scroll completely above the keyboard.
